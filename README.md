# Bess One | Cerveza Artesanal (Landing Page + Carrito)
Desarrollo de una landing page responsiva para mi marca de cerveza artesanal. Implementación de interfaz dinámica con Tailwind CSS, catálogo interactivo con selector de formatos y lógica de carrito de compras en JavaScript con integración a la API de WhatsApp para el envío de pedidos.
